# 1年間の仕事 担任・国語科・陸上部

担任・国語科・陸上部の年間タスクを管理するWebアプリ。データは data.json に保存されます(授業ダイアリーと同じ方式)。

## 置き方
1. 新しいリポジトリを作り、このフォルダの中身をそのままアップロードする(index.html, css/, js/, img/)
2. Settings → Pages → Branch を main / (root) にする
3. GitHubで fine-grained トークンを作る(このリポジトリだけ、Contents: Read and write)
4. https://<ユーザー名>.github.io/<リポジトリ名>/ を開き、「設定」タブにユーザー名・リポジトリ名・ブランチ・トークンを入れて保存

## 今のClaude版のデータを移す
Claude版の「設定」→「書き出し」で出るJSONをコピーし、GitHub版の「設定」→バックアップの欄に貼って「読み込み」。

## 注意
- リポジトリが公開の場合、data.json も誰でも読めます。生徒の氏名・成績などは入れないでください。
- 保存キーは tk.* なので、同じ github.io 上の他アプリ(jd.*)とは混ざりません。
